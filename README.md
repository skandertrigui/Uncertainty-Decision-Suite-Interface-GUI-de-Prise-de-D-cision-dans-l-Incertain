# Uncertainty-Decision-Suite-Interface-GUI-de-Prise-de-D-cision-dans-l-Incertain
Application desktop interactive développée avec Tkinter et NumPy permettant d'analyser une matrice de gains et d'évaluer les meilleures décisions sous incertitude selon 6 critères fondamentaux (Maxmin, Maxmax, Hurwicz, Laplace, Bernoulli, MiniMax Regret) avec visualisation sous forme d'arbre de décision.
